# htaassociates.com

The website of HTA & Associates, served by GitHub Pages from `docs/`.

- Edit pages in `src/build.py`, then run `python3 src/build.py` to rebuild `docs/`.
- The contact email lives in one place: `EMAIL` at the top of `src/build.py`.
- `docs/CNAME` connects the site to htaassociates.com.
